About the Project

This project is a full-stack Employee Onboarding & Management System developed as part of my internship to understand how role-based authentication and employee management work in a real-world application.

The system has separate dashboards for Admin and Employee users. Admins can manage employee records, while employees can access and update their own information securely.

Features Admin Secure Admin Login Create new employee accounts View all employees Edit employee details Delete employees Search employees Pagination for employee records Export employee data to Excel Dashboard with employee statistics Employee Secure Login View personal profile Change password First-time password update Forgot password Logout Tech Stack
